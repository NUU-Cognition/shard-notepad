# Notepad

A persistent, editable brainstorming document with numbered sections, forking, and derivatives. Notepads are conversational — an agent and human exchange messages under incrementing section headings. Supports inline editing of responses and pre/post action patterns for task execution.

## Properties

| Property | Value |
|----------|-------|
| Tag | `#ntpd/notepad` |
| Location | `Mesh/Types/Notepads/` |
| Archive | `Mesh/Archive/Notepads/` |
| Naming | `(Notepad) NNN [Topic Name].md` |
| Numbering | `flint helper type newnumber Notepad` |
